# 功能说明

Creemseed 为个人账户付费的 SaaS 或 Web 产品提供一个精简的全栈起点。内置配置是示例；开始收款前，请按自己的产品调整并验证。

## 应用基础

- Next.js App Router、React、TypeScript、Tailwind CSS 4，以及可复用的界面组件。
- PostgreSQL + Drizzle ORM，迁移文件随代码版本管理。
- 默认英文的公开页面和账户界面、定价页、登录后的用户工作台，以及受保护的管理员后台。
- 支持部署到 Vercel，也可使用独立 Node/Docker 输出。

## 账户与认证

- Better Auth 邮箱密码注册和登录、邮箱验证、密码重置与会话管理。
- 可在 `starter.config.json` 中显式选择 Google 或 GitHub 登录。
- 以个人账户作为计费归属，用户和管理员操作在服务端鉴权。
- 不开放管理员自助注册。先验证普通账户，再按文档命令授予管理员权限。

## Creem 计费

- 通过 Creem 托管结账购买月付和年付订阅。
- 示例订阅目录为每月 USD $9.90、每年 $99，并包含七天试用。创建结账前，服务端会检查 Creem 中的商品配置。
- 可选一次性商品；`hybrid` 和 `onetime` 模式包含一次性商品。
- 客户门户链接、续费状态、周期末取消，以及服务端权益检查。
- 验证签名 Webhook、持久化事件去重、账户级串行处理，并从 Creem 对账当前状态。
- 未完成结账恢复，以及用于查看客户、订阅、结账尝试、Webhook 历史，执行对账和安全重放并查看审计记录的后台。

价格和试用期是模板配置示例。先在自己的 Creem Test 环境创建匹配商品。Test 与 Live 的凭据、商品和 Webhook 端点必须彼此隔离。

## 运维与集成

- 交互式 CLI 会询问项目信息、数据库、登录方式、邮件、计费、分析和部署选项。
- AI 安装提示词会询问同一组场景，并调用同一份经过校验的安装脚本。
- Resend 是可选的事务邮件服务；终端输出仅适用于本地开发。
- PostHog、Vercel Analytics 和 Speed Insights 都是可选项，默认关闭。分析功能需要访客同意，且仅用于所配置的公开页面。
- 提供环境配置检查和只读 Creem 商品目录检查。

## 明确范围

模板不包含团队、席位、按量计费、用量额度或任务队列，也不代表任何第三方账号已经达到生产上线条件。OAuth、邮件发送、Creem 结账/Webhook 和托管都需要在你自己的环境配置并测试。

继续阅读[手动安装](/docs/manual-install)、[AI 安装](/docs/ai-install)或 [Creem 配置指南](/docs/creem)。
